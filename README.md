# Sabrine Modern Portfolio

## Run the project

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Add your CV

Put your CV PDF inside the `public` folder and name it:

`CV.pdf`

## Customize

Edit `src/main.jsx` to change:

- name
- bio
- skills
- projects
- experience
- GitHub / LinkedIn
- email

Edit `src/style.css` to change the colors, animations and layout.

The portfolio includes:

- Responsive React design
- Dark / light mode
- Smooth scrolling
- Animated particles
- Floating hero elements
- Skill progress animations
- Project hover animations
- Responsive mobile menu
- Contact form
- CV download button
